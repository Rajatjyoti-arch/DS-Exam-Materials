## Course Outline [cite: 8]

### UNIT-1: Introduction (10 Lectures) [cite: 9]
* Overview of Big data and Data Science, Evolution of Data Science, Data science Lifecyle. [cite: 9]
* Data mining and its types: Descriptive and Predictive. [cite: 9]
* Data science roles, Applications of Data Science, Data Collection Strategies. [cite: 9]
* Sources of Data: Time Series, Transactional Data, Biological Data, Spatial Data, Social Network Data, Data Evolution. [cite: 9]

### UNIT-II: Exploratory Data Analytics (10 Lectures) [cite: 9]
* **Data Objects and Types:** Attributes and measurements (Nominal, Ordinal, Binary, Numeric: Discrete vs. Continuous), Symmetric vs. Asymmetric attributes. [cite: 9]
* **Basic Statistical Descriptions:** Central Tendency: Mean, Median, Mode. Dispersion: Range, Quartiles, Variance, Standard Deviation, Interquartile Range. [cite: 9]
* **Data Preprocessing:** Need for Preprocessing, Data Cleaning, Data Integration and Transformation, Data Reduction, Ethical Considerations in data science. [cite: 9]
* **Machine Learning for Data Science:** Overview of Machine Learning, Types of Machine Learning: Supervised, Unsupervised, Semi-supervised and Reinforcement learning, Steps for model building. Case studies using k-NN and K-Means. [cite: 9]

### UNIT-III: Using Python for Data Analysis & Visualization (10 Lectures) [cite: 9]
* **Using Python for Data Analysis:** Introduction to Python, Fundamental libraries for data science: Numpy and Pandas, Reading and Handling data, Read and Write Csv Files, Descriptive Statistics using Pandas, Handling Missing Values, Indexing, Selecting and Filtering, Data Normalization. [cite: 9]
* **Data Visualization Tools in Python:** Introduction to Matplotlib, Basic plots using matplotlib, Introduction to Seaborn: Seaborn functionalities and usage, Spatial Visualizations in Python with Folium, Visualizing data: Histograms, Boxplots, Scatterplots. [cite: 9, 10]
